# Demo media

Drop the demo recording assets here. The repo's `../../README.md` references them by relative path; missing files render as broken-image placeholders without breaking the rest of the README.

Expected files:

- `hero.gif`. Full-flow recording (brief to final video). 720x405 (16:9) or 720x1280 (9:16, matches the rendered MP4). Target ≤8 MB so it loads inline on GitHub.
- `cast-canvas.png`. Cast canvas screenshot with character bubbles. 1440x900 PNG.
- `timeline.png`. Shot timeline screenshot with reference stills. 1440x900 PNG.
- `render.png`. Render-screen screenshot with the cost meter and per-shot progress. 1440x900 PNG.

If the bundle gets large, swap `hero.gif` for an MP4 and embed via `<video src="...">`.
